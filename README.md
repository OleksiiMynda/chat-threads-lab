# Багатопотоковий чат на сокетах (Python)

Лабораторна 2: сервер на `127.0.0.1` приймає клієнтів у окремих потоках і пересилає
їхні повідомлення одне одному. Спільний список клієнтів захищено `threading.Lock`,
події пишуться у текстовий файл.

## Швидкий старт

Потрібен Python 3.10+, сторонніх бібліотек немає.

```powershell
python server.py                  # сервер виведе PID і вільний порт
python client.py --port <порт>    # у кількох вікнах
```

Команди в клієнті: `/users` - хто онлайн, `/quit` - вийти. Сервер зупиняється по Ctrl+C.

## Перевірка

```powershell
python stress_test.py             # автотест: багато клієнтів, обриви, цілісність журналу
python file_io_experiment.py      # запис у файл з кількох потоків: з Lock і без
.\inspect_server.ps1              # PID, порт і TCP-з'єднання сервера (netstat / PowerShell)
```

## Що де

| Файл | Призначення |
|---|---|
| `server.py` | сервер, спільний список клієнтів, журнал `chat_log.txt` |
| `client.py` | консольний клієнт |
| `stress_test.py` | автоматична перевірка |
| `file_io_experiment.py` | дослідження файлового вводу-виводу |
| `inspect_server.ps1` | дослідження процесу й з'єднань |
| [REPORT.md](REPORT.md) | повний звіт: рішення, синхронізація, результати netstat і експериментів |
